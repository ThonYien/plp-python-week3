# PLP Python Week 3

This repository contains my Python Week 3 assignment.

- `grade_reporter.py` - Calculates and reports grades, pass/fail counts, and the average score.
- `bug_hunt.py` - Finds and fixes three bugs in a Python program that calculates the sum from 1 to 5.

The hardest bug to find was the loop condition because the program could run without showing an error message. I knew something was wrong because the program printed an incorrect answer instead of 15.
